# WiFiSense

WiFiSense is a real-time Wi-Fi monitoring and network diagnosis platform that continuously collects network telemetry such as signal strength (RSSI), Wi-Fi channel, link rates, latency, and packet loss. It analyzes these metrics to identify network issues and provides clear insights into the current network health.

The project also includes scenario simulation to reproduce conditions such as weak signal, high latency, packet loss, and connectivity issues, making it useful for testing and demonstrating network diagnostics.

### Key Features

* Real-time Wi-Fi telemetry collection
* RSSI, SSID, BSSID, channel and RX/TX link-rate monitoring
* ICMP-based latency and packet-loss measurement
* Rule-based network condition detection
* Network health monitoring
* Scenario simulation for different network conditions
* Live dashboard for visualizing telemetry and diagnostics

**Built for network visibility, troubleshooting, and intelligent Wi-Fi diagnostics.**
